# SkillGap AI
### Cloud-Based Intelligent Job Discovery & Career Recommendation Platform

## Project Overview
SkillGap AI is a career recommendation platform designed to help candidates identify their skills, understand skill gaps, and discover suitable job opportunities based on their resumes.

## Problem Statement
Candidates often find it difficult to understand which skills are missing from their resumes for their desired jobs. SkillGap AI aims to make this process easier through resume analysis and job-skill comparison.

## Objectives
- Extract skills from uploaded resumes.
- Compare candidate skills with job requirements.
- Calculate a job-skill match score.
- Identify missing skills.
- Suggest a learning roadmap to improve job readiness.

## Key Features
- Resume upload and text extraction.
- Initial skill extraction using Python.
- Job requirement comparison (planned).
- Match score and missing-skill analysis (planned).
- Career recommendations and learning roadmap (planned).

## Technology Stack

**Current prototype:** Python, FastAPI, Uvicorn, PyMuPDF, python-docx, and dictionary-based skill extraction.

**Planned technologies:** React.js, PostgreSQL, AWS, Docker, and GitHub Actions.

## Current Implementation Status
The current work focuses on the FastAPI backend, resume text extraction, and initial skill extraction. The React dashboard, database integration, advanced semantic matching, and cloud deployment are planned future tasks.

## Future Scope
- Develop a React-based dashboard.
- Improve job matching using NLP and machine learning.
- Integrate authorized job data sources.
- Add cloud-based deployment and monitoring.
